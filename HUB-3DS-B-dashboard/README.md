## Funciones
- Menú lateral con navegación a secciones.
- Búsqueda de clases.
- Tema claro/oscuro.
- Accesos a recursos de HTML, CSS, JavaScript y Git.
- Mini quiz con retroalimentación.
- Diseño adaptable a celular.

## Probar
Abre `index.html` directamente en el navegador o con Live Server desde Visual Studio Code.

## Publicar
Sube `index.html`, `css/` y `js/` a un repositorio público de GitHub. En Settings → Pages selecciona Deploy from a branch, rama `main` y carpeta `/ (root)`.
